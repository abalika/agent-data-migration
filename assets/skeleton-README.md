# <应用名> 目录说明

本目录由 `agent-data-migration` 技能整理，遵循"一个应用一个根"的结构。

| 目录 | 放什么 | 能不能删 |
| --- | --- | --- |
| `projects\` | 长期维护的工程（有 README / git / 产物） | 按需 |
| `chats\` | 一次性对话工作区、交付物 | 按需 |
| `_runtime\` | 应用自己会去找的：数据根、插件、缓存、运行时 | **不要删**，删了应用起不来 |
| `maintenance\` | 备份、归档、诊断脚本、旧版本安装 | 确认后可清 |

## 回退

每个批次在 `maintenance\<批次>-<日期>\` 下有：

- `REPORT.md`：映射表、验收结果、事故记录、回退步骤
- `backup\`：原配置与数据库快照
- `journal.json`：逐项操作日志，可用 `apply.py --rollback` 反向执行

## 注意

- `_runtime` 里可能包含指向原位置的目录联接（junction），这是应用的数据入口，**不是残留**
- 迁移后如出现异常，先看 `maintenance\<批次>\REPORT.md` 的"事故与修复"一节
